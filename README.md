# STUDI_KASUS_5-SORAYA-GHINA-2609116081

Program ini digunakan untuk menghitung biaya pemesanan kamar hotel berdasarkan jenis kamar dan lama menginap. Function hitung_biaya() digunakan untuk menentukan tarif kamar Standard atau Deluxe, lalu menghitung total biaya dan mengembalikannya dengan return.

Function pesan_hotel() digunakan untuk memasukkan data pemesanan seperti jenis kamar, tanggal check-in, check-out, dan lama menginap. Setelah itu, hasil perhitungan ditampilkan.

Pada bagian menu, while True digunakan agar menu terus berjalan. Pilihan 1 untuk memesan kamar, sedangkan pilihan 2 untuk keluar dari program menggunakan break.
